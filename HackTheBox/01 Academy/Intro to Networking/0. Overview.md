Access Control List - analogy - like putting fence around property border with specific entry and exit points. Makes it easier to detect suspicious activities. E.g. printer networking talking to server over HTTP.
Map out/document each network's purpose - make sure all activity can be seen around the property
Intrusion Detection System - like putting bushes around windows so people don't come through them. E.g. why did a port scan originate from the printer network? 

1. Web server should be in DMZ - clients on internet can initiate communications with the website. Administrators can put networking protections between the web server and other devices by placing it in a separate network.
2. Workstations should be on their own network, and ideally each workstation has a Host-Based Firewall rule preventing it from talking to other workstations. If a workstation is on the same network as a server, they can be vulnerable to networking attacks like spoofing or man in the middle.
3. The Switch and Router should be on an "Administration Network." This prevents workstations from snooping in on any communication between these devices., 
4. IP Phones should be on their own network. Own network allows traffic to be prioritised to prevent high latency more easily.
5. Printer should be on their own network. Cannot secure a printer. If a printer tells a computer authentication is required during a print job, the computer will attempt an NTLMv2 authentication, which can lead to passwords being stolen. Printers are great for persistence, and have tons of sensitive information sent.
