- Virtual hosting enables multiple websites or domains to be served from a single server or IP address. Each vhost is associated with a unique domain name or hostname.
- hen a client sends an HTTP request, the web server examines the `Host` header to determine which vhost's content to deliver.
- Subdomains are extensions of a primary domain name, creating a hierarchical structure within the domain. Unlike vhosts, subdomains are resolved to specific IP addresses through DNS (Domain Name System) records. 

| Feature        | Virtual Hosts                                                            | Subdomains                                                                  |
| -------------- | ------------------------------------------------------------------------ | --------------------------------------------------------------------------- |
| Identification | Identified by the `Host` header in HTTP requests.                        | Identified by DNS records, pointing to specific IP addresses.               |
| Purpose        | Primarily used to host multiple websites on a single server.             | Used to organize different sections or services within a website.           |
| Security Risks | Misconfigured vhosts can expose internal applications or sensitive data. | Subdomain takeover vulnerabilities can occur if DNS records are mismanaged. |

#### Gobuster
- `Directories`: Discover hidden directories on a web server.
- `Files`: Identify files with specific extensions (e.g., `.php`, `.txt`, `.bak`).
- `Subdomains`: Enumerate subdomains of a given domain.
- `Virtual Hosts (vhosts)`: Uncover hidden virtual hosts by manipulating the `Host` header.
- VHost Fuzzing - `Gobuster` takes each word from the wordlist, appends the base domain to it, and then sends an HTTP request to the target URL with that modified `Host` header
- add specified vhost to hosts file `echo "IP inlanefreight.htb" | sudo tee -a /etc/hosts` . Run gobuster command `gobuster vhost -u http://inlanefreight.htb:81 -w /usr/share/seclists/Discovery/Web-Content/common.txt --append-domain`
- vhost parameter - for vhost fuzzing mode.
- -u flag to specify URL, -w for wordlist and --append-domain command to append the base domain to each word in the wordlist
- Subdomain fuzzing - `gobuster dns -d inlanefreight.com -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt`
- dns parameter for DNS fuzzing mode
- -d flag to specify target domain

#### FFUF
- use -H to specify host head, e.g. `-H ‘Host: FUZZ.fuzzing_fun.htb’`
