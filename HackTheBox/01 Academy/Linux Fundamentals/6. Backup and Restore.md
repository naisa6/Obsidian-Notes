#### Rsync, Deja Dup and Duplicity
- all available on Ubuntu
- Rsync - open-source, fast and secure. Supports local and remote. Can transfer only portions of files that have changed, efficient in dealing with large amounts of data. Useful for network transfers, e.g. syncing files between servers or creating incremental backups on the Internet.
  `sudo apt install rsync -y`  copy the entire directory (`/path/to/mydirectory`) to a remote host (`backup_server`), to the directory `/path/to/backup/directory`
  Restoring backup - `rsync -av user@remote_host:/path/to/backup/directory /path/to/mydirectory`
  `rsync -av /path/to/mydirectory user@backup_server:/path/to/backup/directory`
  Secure transfer of backup: `rsync -avz -e ssh /path/to/mydirectory user@backup_server:/path/to/backup/directory`
- Duplicity - Rsync with encryption. can encrypt backup copies for secure storage on remote servers, FTP sites, cloud services like Amazon S3.
