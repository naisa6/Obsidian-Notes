#### SSH 
- network protocol that allows the secure transmission of data and commands over a network. Used to securely manage remote systems and securely access remote systems to execute commands or transfer files. SSH server must be available and running in order to connect. 
- Most commonly used SSH server is the OpenSSH server. 
- Installing OpenSSH - `sudo apt install openssh-server -y`. Can check if it is running by `systemctl status ssh`.
- OpenSSH can be configured and customized by editing the file `/etc/ssh/sshd_config`
- adjust settings such as the maximum number of concurrent connections, the use of passwords or keys for logins, host key checking, etc.
#### NFS
- Network File System (`NFS`) - network protocol to store and manage files on remote systems as if they were stored on the local system - easy and efficient management of files across networks.
- features such as access controls, real-time file transfer, and support for multiple users accessing data simultaneously
- installing NFS - `sudo apt install nfs-kernel-server -y` and to check if running: `systemctl status nfs-kernel-server`
- configure NFS via the configuration file `/etc/exports` - file that specifies which directories should be shared and the access rights for users and systems and settings such as the transfer speed and the use of encryption

| Permission     | Description                                                                                                                                                |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| rw             | Gives users and systems read and write permissions to the shared directory.                                                                                |
| ro             | Gives users and systems read-only access to the shared directory.                                                                                          |
| no_root_squash | Prevents the root user on the client from being restricted to the rights of a normal user.                                                                 |
| root_squash    | Restricts the rights of the root user on the client to the rights of a normal user.                                                                        |
| sync           | Synchronizes the transfer of data to ensure that changes are only transferred after they have been saved on the file system.                               |
| async          | Transfers data asynchronously, which makes the transfer faster, but may cause inconsistencies in the file system if changes have not been fully committed. |
- Create NFS Share 
  ```
  mkdir nfs_sharing && echo '/home/username/nfs_sharing hostname(rw,sync,no_root_squash)' >> /etc/exports && cat /etc/exports | grep -v "#" /home/username/nfs_sharing hostname(rw,sync,no_root_squash)
  ```
  - Mount NFS Share
```
mkdir ~/target_nfs && mount 10.129.12.17:/home/john/dev_scripts ~/target_nfs && tree ~/target_nfs
```
i.e,. mounted the NFS share (`dev_scripts`) from our target (`10.129.12.17`) locally to our system in the mount point `target_nfs` over the network and can view the contents just as if we were on the target system

#### Web Server
- web server is software that delivers data, documents, applications, and various functions over the Internet
- utilizes the Hypertext Transfer Protocol (`HTTP`) to transmit data to clients such as web browsers and to receive requests from these clients
- received data is then rendered as Hypertext Markup Language (`HTML`) within the client's browser
- common web servers on Linux platforms: Apache, Nginx, Lighttpd, and Caddy
- installing Apache Web Server `sudo apt install apache2 -y` - to specify which folders can be accessed, we can edit the file `/etc/apache2/apache2.conf`. E.g.
  ```
  <Directory /var/www/html>
	  Options Indexes FollowSymLinks
	  AllowOverride All
	  Require all granted
  </directory>
  ```
- default `/var/www/html` folder is accessible, that users can use the `Indexes` and `FollowSymLinks` options, that changes to files in this directory can be overridden with `AllowOverride All`, and that `Require all granted` grants all users access to this directory. E.g., if we want to transfer files to one of our target systems using a web server, we can put the appropriate files in the `/var/www/html` folder and use `wget` or `curl` or other applications to download these files on the target system. 
  Also possible to customize individual settings at the directory level by using the `.htaccess` file, which we can create in the directory in question. This file allows us to configure certain directory-level settings, such as access controls, without having to customize the Apache configuration file. We can also add modules to get features like `mod_rewrite`, `mod_security`, and `mod_ssl` that help us improve the security of our web application.
- Python Web Server is a simple, fast alternative to Apache and can be used to host a single folder with a single command to transfer files to another system. Installing: `sudo apt install python3 -y && python3 -m http.server` Python Web Server will be started on the `TCP/8000` port, and we can access the folder we are currently in. can also host another folder with `python3 -m http.server --directory /home/username/target_files`. On Python web server can transfer files to the other system by typing the link in our browser and downloading the files. Host Python web server on a port other than the default port: `python3 -m http.server 443`
#### VPN
- Virtual Private Network (`VPN`) functions like a secure, invisible tunnel that connects user to another network, allowing seamless and protected access as if physically present within it.
- establishes an encrypted tunnel between the client and the server, ensuring that all data transmitted through this connection remains confidential and safeguarded from unauthorized access.
- Organizations primarily utilize VPNs to grant their employees secure access to the internal network without requiring them to be on-site. This flexibility enables employees to reach internal resources and applications from any location, enhancing productivity and mobility. Additionally, VPNs serve to anonymize internet traffic and block external intrusions, further bolstering security.
- Common VPN for Linux servers are OpenVPN, L2TP/IPsec, PPTP, SSTP, and SoftEther
- Install using: `sudo apt install openvpn -y` and customized and configured by editing the configuration file `/etc/openvpn/server.conf` and can change the settings to configure certain features such as encryption, tunneling, traffic shaping, etc.  To connect to an OpenVPN server, use the `.ovpn` file we received from the server and save it locally. Run `sudo openvpn --config internal.ovpn`
#### Working with Web Services
- Apache can be extended with modules, each designed for a specific purpose.  Securing communication, rerouting traffic, or dynamically shaping content.
  Features - mod_ssl - encrypts data, securing the communication between the browser and the web server. mod_proxy - directs traffic to correct destination, especially useful when setting up proxy servers. `mod_headers` and `mod_rewrite` fine control over the data traveling between browser and server, allowing you to modify HTTP headers and URLs on the fly. Common  server-side scripting languages: PHP, Perl, and Ruby. Python, JavaScript, Lua, or even .NET are also compatible. can edit the `/etc/apache2/ports.conf` file - set port to 8080.
  After starting server, browse to http://localhost:port_number or curl -I http://localhost:port_number

#### cURL and Wget
- cURL - allows file transfer from shell over protocols like `HTTP`, `HTTPS`, `FTP`, `SFTP`, `FTPS`, or `SCP`. 
- `curl` returns the website’s page source as STDOUT - allowing for inspection of the source code of the website and getting information from it.
- wget - can download files from FTP or HTTP servers directly from the terminal. Website content is downloaded and stored locally.
- Python3 - `python3 -m http.server`
